我的 GitHub 里有个仓库，readme 上写着一句几乎没修饰过的话：

> This is my learning record. Begin from 2025.04.03. I want to get away from chemical engineering rubbish.

2025 年 4 月 3 日，一个化工人决定学 Python，理由是"逃离化工垃圾"。今天翻回去看，这个仓库已经攒下了 213 个 Python 文件、大约四千行代码，还有一路走来的全部笨拙和诚实。这篇就是它的总结。

## 路线：一本教科书打地基，两座刷题山练内功

回头看，我的学习路线几乎是教科书式的：

1. **《Python 编程：从入门到实践》**：从第 3 章一路刷到第 11 章——列表、字典、循环、函数、类与继承、文件与 JSON、异常处理，最后一章还老老实实写了 pytest 单元测试；
2. **代码随想录**：手写数据结构与算法。链表、各种排序、栈和队列、二叉树、字符串、哈希表，一个不落；
3. **LeetCode**：刷了二十多道经典题——两数之和、接雨水、滑动窗口、组合总和、桶排序……
4. **用回现实**：用 numpy 和 matplotlib 画企业的分段成本函数，在 Bohrium 科学计算平台上做数据统计练习。

## 进步是看得见的

最让我有成就感的是几处"多解法留痕"：

- **接雨水**：一个文件里存了六种解法，从暴力 O(n²) 到动态规划、双指针、单调栈，思维进化的全过程都躺在注释里，甚至还包括一条改错记录——"原代码此处存在逻辑错误"，后面跟着修复。
- **手写链表**：同一个数据结构重写了三遍，最后一版里出现了 dummy 头结点，还有一句主动的"优化点：复用 addAtIndex 方法，减少代码重复"。原来重构意识真的是练出来的。
- **二叉树统一迭代法**：用 `(node, visited)` 元组标记，一个模板统一前中后序遍历。第一次写出它的时候，是真有"原来如此"的瞬间。

## 错误也都留着

这个仓库不完美，甚至可以说很不完美：`practice` 拼成 `practise`，枚举拼成 `enmuation`；最早那次算法效率实验，计时代码打印的是 `start_time - end_time`，负数；还有几个建了文件没写完的题。

但我决定不改。错误和进步原样留在一起，才是学习记录该有的样子——一年后再看，负数的计时器和正确的单调栈同样珍贵。

## 彩蛋：二叉树目录里的一朵玫瑰

学 turtle 的时候画过一朵红玫瑰。后来学了 numpy 参数方程，又画了一朵 3D 的——它被放在了 `binarytree` 目录里（我也不知道当时怎么想的），标题是 "Ling ❤ Neo, 2025"，代码最后一行写着：

```python
# My love for you is an infinite loop, unbreakable and eternal
```

程序员的浪漫，大概就是这样藏在自己都想不到的地方。

## 写在最后

从 Hello World 到单调栈，从转行宣言到 3D 玫瑰，这一年最大的收获不是四千行代码，而是确认了一件事：**转方向这件事，起点低不可怕，停下来才可怕。**

博客叫 Becoming——我还在成为自己的路上。
